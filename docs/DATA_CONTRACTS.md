# Data contracts

The site consumes only `site/public/data/*.json`, validated against `data/contracts/<name>.schema.json` (JSON Schema 2020-12, generated by
`pipelines/contracts.py`, the single source of truth). TypeScript types are generated from these files. Conventions follow P01/P02:
`schema_version: "v1"`, a `tags` map (field group to honesty tag), compact JSON, sorted keys, no NaN (missing is `null`, never zero, never interpolated).
Tags: OBSERVED / DERIVED / PREDICTED / SIMULATED / SYNTHETIC (SIMULATED and SYNTHETIC unused), "/" combinations allowed.

## Conventions
- **Countries:** `iso3` list order is fixed by `countries.json` (217 entries, sorted by iso3). Every country-major array uses that order.
- **Years:** `years` is a list (1990 to the last WDI year); panel rows are country-major: `values[country_index][year_index]`.
- **Money basis (type-level PPP vs nominal):** every level indicator has `price_basis` in `current_usd | constant_usd_<yr> | ppp_constant_intl_<yr> | maddison_intl_2011`; non-money series have `null`.
  Level comparisons, rankings, regressions and cluster features must use one basis. The reference implementation is `analytics/units.py::assert_same_basis`, which raises `MixedBasisError`.
  Browser code must reproduce this guard (`indicators.json` is the lookup).
- **Latest year:** per indicator, the latest year whose country count is at least 90 percent of that indicator's peak yearly count in 2010 to 2022 (rule and N published in `coverage.json` and `indicators.json`).
- **Rankings:** only countries with a value that year; `n` published; ties broken by iso3; descending by value.
- **Growth figures:** `100*(ln y_end - ln y_start)/(end-start)`, percent per year (log growth rate), DERIVED.
- **Size budget:** each artifact under 400 KB gzip; measured sizes in `meta.json.artifact_bytes`.

## Raw / interim (not published)
`data/raw/**` (gitignored; `uv run python -m pipelines.ingestion.fetch` re-creates it), `data/interim/*.parquet` (cleaned long panel), `data/manifests/{raw_manifest,cleaning_ledger}.json`.
Interim long panel: `(iso3, year, indicator, value)`.

## Boundary table semantics
`boundaries.json.rows[]`: `iso3`, `entity`, `event`, `event_year`, `event_evidence` (`GENERAL_KNOWLEDGE`), `first_year_observed` (`DATA`, per `gdppc_const`),
`territory_break_year` (year inside the WDI series after which territory differs, or null), `treatment` (text), `sensitivity_only` (bool).
A country with `territory_break_year` inside (start, end] of a beta window is excluded from the primary sample of that window and included in the `sensitivity_all` record.
Countries with no data at the window start drop out of that window automatically (listed in the record's `dropped_no_start_data`).

## Seed-head data requests DR-1..DR-8 (P05-DATA-002; VISUAL_DESIGN 6.2)
| ID | Status | Where and how |
|---|---|---|
| DR-1 | Done, with one declared deviation | `seedhead/<indicator>.json` per rankable indicator (17 files; `gdppc_ppp` has every year 1990 to latest, warm-started year to year; others have `rankings.snapshot_years` + latest where n >= 30) and `seedhead/gdppc_ppp_latest.json`. Schema `seedhead.schema.json`. Lattice: Vogel, golden angle 137.50776 degrees, slot area 1, one slot = 1,000,000 people. **Counts:** `max(1, floor(pop/1e6 + 0.5))` per country (half-up, per country, independent of sort order); population is the published `panel_income.population` value (rounded to 0 decimals) of the same year. A country under 0.5M people holds one slot drawn at `area_scale = pop / (count x 1e6)` (less than 1). `order` is descending by the indicator's published (rounded) value, ties by iso3, identical to `rankings`. `owner[i]` is the index into `order` of the country holding lattice slot i (base64 uint8; at most 217 countries). `no_data` lists countries with population but no indicator value that year (their people are not drawn). `median_person` is the country containing the median person among people-with-data ranked by the indicator. **Algorithm:** the reference `design/sketches/territories.py` (power assignment with weights, centroid relaxation, exact greedy repair), ported to `analytics/seedhead.py` (same cost and update rules; the squared distance is computed by the expanded square, iterations 600 cold start, 200 warm start). **Deviation:** the reference leaves 17 to 39 of 185 territories fragmented (checked on 2025), so a deterministic count-preserving contiguity repair (`polish`: stranded fragment handed to a neighbour, ripple of boundary grains back to the owner) is added after the greedy repair. Connectivity is the fraction of a territory's slots in its largest 6-nearest-neighbour component; per layout `connectivity.{min, mean, below_95}` is published, and the tests state the achieved result rather than assuming it. Warm start uses each country's previous centroid; a country absent the previous year gets its rank seed. Size and byte-identical reruns are tested. |
| DR-2 | Done | Each seedhead file carries `source.panel_income_sha256` (sha256 of `panel_income.json`). Tests recompute counts from `panel_income.population` and orders from `panel_income` values and compare with the files and with `rankings` (same published rounded values; `rankings` is now computed from the rounded published values so ties agree). |
| DR-3 | Done | `facts`: `gdppc_ppp_top_iso3`, `gdppc_ppp_bottom_iso3` (string facts, same `{value, unit, tag}` shape), `gdppc_ppp_top_bottom_ratio`, `gdppc_ppp_people_with_data_billion`, `gdppc_ppp_nodata_countries`, `gdppc_ppp_nodata_people_billion`, `median_person_gdppc_ppp` and `median_person_iso3` (latest year), `_1990` variants, `seedhead_slots_1990`, `seedhead_slots_latest`, `ppp_const_rank_rho` (Spearman of PPP vs constant-USD GDP per capita, 2019, from `validation`; a sanity statistic, not a comparison of levels). Top and bottom are among countries with PPP data in the latest year, including very small economies. |
| DR-4 | Done | `correlations.iso3` (217) and `correlations.values` = `{variable: [217 values or null]}` for the 10 variables over `correlations.window`, rounded to 6 decimals, exactly the vectors used for rho; `correlations.transforms` gives each variable's transform. Test recomputes rho for every pair from these values (tolerance 1e-5). |
| DR-5 | Done | `clusters.hierarchical.labels_matched` (Ward labels mapped to k-means ids by Hungarian assignment on the contingency table, maximising overlap), `disagree_count`, `match_rule`. `assignments.iso3` and `assignments.silhouette` are in the same order (tested). |
| DR-6 | Done | Per `convergence.beta[]`: `vcov_hc3` (2x2, order intercept then slope; `vcov[1][1] = se_hc3^2`, tested), `x_domain` (min, max of ln start income), and `points.population_start` (persons at the start year) on every record with points. |
| DR-7 | Done | `indicators[].display` = `{scale, bins (6 edges, strictly increasing), edge_labels, short_label, indexable, core_reads, bins_rule, pooled_years, pooled_n}`. Edges are fixed per indicator, computed once from all published values pooled over 1990 to the last year (so legends do not move with the year): equal-count quantiles at k/7 for level, share, rate and count series (`scale` says how to draw them: log for money levels and population, asinh for inflation, linear otherwise); growth is `diverging` with symmetric edges +-a, +-b, +-c at the 0.2, 0.5, 0.85 quantiles of |value|. If quantile edges collide the rule falls back to equal width between the 1st and 99th percentile and says so in `bins_rule`. `indexable` is true only for positive ratio-scale levels (GDP per capita in all three bases, productivity, population). |
| DR-8 | Done, as `narratives.pair_templates` / `pair_examples` (not inside `templates`) | The single-country `templates` list stays exactly as the UI binds it. Pair families: `compare_level`, `compare_growth_1990`, `_2000`, `_2010`, `compare_index_2000`. Placeholders: `{a.key|fmt}`, `{b.key|fmt}` read published per-country inputs; `{diff.key|fmt}` = a - b and `{ratio.key|fmt}` = a / b are the only operations (simple subtraction/ratio of two published inputs, the template's `requires` names them). `compare_level` uses PPP only (both inputs are PPP-basis keys, so mixing is impossible by construction). `pair_examples` hold reference renderings for 5 pairs (all five templates each); Python `render_pair` is the parity reference. |
